VAPT Lab (Vulnerability Assessment and Penetration Testing Lab) is an intentionally vulnerable web application built to help users understand and practice common web security vulnerabilities in a safe environment. The platform provides hands-on labs covering topics such as Cross-Site Scripting (XSS), NoSQL Injection, Weak Session Management, Insecure File Uploads, and other OWASP Top 10 vulnerabilities.

Each lab demonstrates how a vulnerability can be exploited, why it occurs, and the security impact it can have on a web application. The goal is to strengthen practical cybersecurity skills by combining secure coding concepts with real-world attack scenarios.
