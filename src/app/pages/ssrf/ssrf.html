What Happened?

The URL you entered was not requested by your browser. Instead, the Express server used axios.get() to fetch the URL and then returned the response back to you.

If an attacker supplies an internal URL such as: 

http://localhost:5000/api/internal/secret

the server may expose internal resources that should never be publicly accessible. This vulnerability is known as Server-Side Request Forgery (SSRF).
